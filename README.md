### What I build

| Project | What's interesting about it |
| :-- | :-- |
| **[Docket](https://github.com/ysta32/Docket-App)**<br/><sub>Swift · SwiftUI · SQLite</sub> | A local-first macOS to-do app you type to like a text. Its date parser reads English and Chinese, and shows an amber **?** instead of guessing when a date is ambiguous. It also ships its own MCP server, so Claude can add tasks directly. |
| **[Plec Concierge](https://github.com/ysta32/PlecAIHackathon)**<br/><sub>JavaScript · Node</sub> | A booking agent built at a hackathon. A tool-calling loop over a live booking API, where bookings are blocked in code until the user gives a clear yes. Passes 60/60 tests. Built with Bryan Chen. |
| **[Swiffle](https://github.com/ysta32/Swiffle)**<br/><sub>React · Express · Socket.IO</sub> | Real-time multiplayer SAT battles. Rooms run over Socket.IO, scores decay with answer time, and a 1v1 mode turns score gaps into HP damage. |
| **[Zeno](https://github.com/ysta32/ZenoStableCoin)**<br/><sub>React · TypeScript · Vite</sub> | A prototype stablecoin payroll dashboard for founders paying contractors across time zones. [Live demo](https://zeno-stable-coin.vercel.app). |

I also design custom PCBs and embedded systems, and I run multi-agent Claude Code workflows to build software in parallel.
